# 网页交互修复验证 — 2026-09-15

## 修复范围

- 术语库全部写入入口采用候选数据事务：写入成功才替换列表、清空表单及显示成功；失败时保留输入、原数据和待保存候选，支持重试、导出、明确放弃及离开提醒。
- 逐行勾选同步全选/半选；筛选或重绘清空选择，批量删除仅处理可见选中项。
- 账户摘要分模块加载，普通失败保留会话及已展示数据；首次失败不显示虚构套餐/额度；支持刷新恢复及会话失效返回登录。
- 防止退出、换号、重叠请求的迟到响应覆盖账户状态；站内登录返回不等待摘要接口。
- 登录模式切换同步 tabIndex/aria-selected，重置密码后聚焦账号输入。
- 600px 以下账户摘要卡片单列，避免失败提示被压成竖向短行；视觉体系不变。
